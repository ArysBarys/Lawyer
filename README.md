# ADALTIREK — Одностраничный юридический сайт

Это минимальный одностраничный сайт юридической компании ADALTIREK.

- Откройте `index.html` в браузере для просмотра.
- Основные файлы: `index.html`, `styles.css`, `script.js`.
- Изображения размещены в `assets/`.

Что сделано:
- адаптивный дизайн с секциями "О нас", "Услуги", "Преимущества", "Полезные материалы" и контактной формой;
- переключатель языка EN/RU/KK с сохранением выбора в браузере;
- простая фронтенд-валидация формы и уведомления о результате;
- метаданные SEO и Open Graph.

## Настройки

1. Измените текст и контакты непосредственно в `index.html` или в объекте `translations` в `script.js`.
2. Замените `assets/adaltirek-hero.jpg` и `assets/adaltirek-logo.jpg` при необходимости.
3. Если нужен реальный backend для формы, добавьте серверную логику или сервис отправки email.

## Лицензия

Файлы свободны для редактирования и использования в вашем проекте.
